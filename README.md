# CPU 进程与主存调度模拟

基于 **Python + PyQt5** 的图形化调度模拟程序，实现三核 CPU 抢占式优先级调度与主存动态分区管理，通过界面观察进程状态变化和内存分配情况。

## 基本功能

- **进程调度**：模拟三个 CPU 核心，高优先级进程可抢占运行中的低优先级进程；等待中的就绪进程会逐步提升优先级。
- **进程管理**：设置进程名、优先级、运行时间和内存需求，支持添加、终止、挂起、解挂及系统重置。
- **内存管理**：采用可变分区首次适应算法，支持内存分配、回收与相邻空闲分区合并。
- **状态可视化**：显示后备、就绪、运行和挂起队列，以及剩余运行时间、内存占用比例和已分配内存块。

## 运行方式

在仓库根目录安装依赖并启动：

```bash
pip install PyQt5
python Main.py
```

在界面中填写进程参数并添加进程，即可观察调度和内存变化；选中对应队列中的进程可进行终止、挂起或解挂操作。

## 主要文件

- `Main.py`：程序入口、界面交互与状态显示。
- `Core.py`：进程调度、状态切换与运行计时。
- `Memory.py`：内存分配、释放与空闲分区合并。
- `Class.py`、`Global_var.py`：进程控制块、内存分区及共享状态。
- `MultiThread.py`：调度后台线程定义。
- `Window.ui`、`Window.py`：Qt Designer 界面文件及生成代码。
